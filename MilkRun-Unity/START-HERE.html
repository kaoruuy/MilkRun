Unity 6.3 LTS 6000.3.27f1

ミルク防衛隊 0.18.0

Windowsで編集を再開する手順です。赤ちゃんにミルクを届け、東西のおうちを守る三人称タワーディフェンスのUnityプロジェクトを同梱しています。

最初に開く 動作を確認する 編集箇所を探す Windows版を作る チームに渡す

Windowsで開く

  1. エクスプローラーでZIPを右クリックし、「すべて展開」を選びます。作業先は %USERPROFILE%\UnityProjects など、PC上のフォルダーが分かりやすいです。
  2. Unity Hubを起動し、各自のUnityアカウントでサインインしてライセンスを有効にします。Editorは、この版の保存・ビルドに使用した 6000.3.27f1 を選びます。
  3. Unity Hubの「プロジェクト」→「追加」→「ディスクから加える（Add project from disk）」で、展開した MilkRun-Unity フォルダーを選びます。直下に Assets、Packages、ProjectSettings が並んでいる階層です。
  4. プロジェクト一覧から開き、初回のインポートを待ちます。Editorの Assets/Scenes/ToyGarden.unity を開いて、上部の ▶ を押します。タイトルに 体験版 0.18.0 と表示されます。

Unity標準の Audio・IMGUI・Physics を使っています。日本語フォント、効果音、BGM、見た目に必要な素材も Assets に入っています。

初回の動作確認

  1. 導入　「プレイする」から紙芝居を進めます。右上 → 左上 → 右下 → 左下の順です。保育士を動かして屋台へ行くとミルクを受け取り、赤ちゃんに近づくと自動で渡します。
  2. チュートリアル　ハートが盾なしピーマンを倒し、盾持ちには弾かれることを確認します。ミルクを持って攻撃を試すと案内が出ます。床に置いてから、盾を割り、本体を攻撃します。
  3. 1面　東西のおうちを2分守ります。残り1:00でおじいちゃんが初登場、0:00で王冠ピーマンが出ます。倒すと報酬の3択に進みます。
  4. 2面　報酬を選んで決定し、お菓子の町へ進みます。1分15秒経過でクッキー将軍が東から現れ、撃破するとクリアです。

2面をすぐ試す　ゲーム画面を選び、P を押したまま A を押すと報酬選択へ移動します。「この報酬で2面へ」を選びます。

操作　WASDで移動、マウスで視点、ホイールで距離、Spaceでジャンプ、Mで地図。Fまたは左クリックで攻撃。Eまたは右クリックで瓶を置く・拾う。寝返った子の近くで、手ぶらのままEまたは右クリックを5秒長押しするとなだめられます。

どこを直すか

Play開始時に MilkRun.cs の Launch() が起動します。庭やキャラクターの大部分はコードから生成されます。配置や見た目を変えるときは、下のスクリプトを編集してもう一度Playします。

変えたいもの最初に見るファイル
プレイヤー操作・ミルク・お世話MilkRun.cs の HandleCare()・UpdateChildren()。保育士の造形は ToyArt.cs の Keeper()。
チュートリアルMilkRunGuide.cs に進行と2体のピーマン、MilkRunScenes.cs にカメラと説明。
タイトル・紙芝居・HUDMilkRunUI.cs に表示とボタン、MilkRunOpening.cs に紙芝居の絵と文章、MilkRunEncounters.cs に初登場・寝返りの演出。
敵の出現・ボス1面は MilkRun.cs の waves と types、2面は MilkRunTown.cs の TownWaves と TownFoes。時刻と敵の種類は同じ添字で対応します。ボスと敵HPは MilkRunSiege.cs。
マップ・報酬・音道や配置は ToyGarden.cs、地図UIは MilkRunMap.cs、報酬とミルクどろぼうは MilkRunTown.cs。音の処理は MilkRunMusic.cs と MilkRunSounds.cs。

上のスクリプトは Assets/Scripts にあります。詳しい仕様とファイル一覧は同梱の プロジェクトREADME を参照してください。

Windows版を作る

  1. UnityのPlayを停止し、メニューの Milk Run → Build for Windows を選びます。ビルド先はWindows 64-bit、スクリプトバックエンドはMonoです。
  2. プロジェクト内の Builds/StandaloneWindows64/ に出力された Milk Run.exe を起動し、変更した場面を確認します。
  3. プレイ用に渡すときは、StandaloneWindows64 フォルダーごとZIPにします。実行には Milk Run_Data やDLLも必要です。

次の版番号を付ける場所は、Assets/Editor/DemoBuild.cs の bundleVersion と、Assets/Scripts/MilkRunUI.cs のタイトル表示です。Build for Windowsの実行時に ProjectSettings の版番号も更新されます。
