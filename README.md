# MILK RUN ／ ミルク防衛隊 0.18.0

赤ちゃんにミルクを届けながら、東西にある2つのおうちを守るゲームです。1面で2分間の防衛を耐えて王冠ピーマンを倒すと、報酬を選んで2面へ進みます。

## 制作のきっかけ・公開先

本作は、AIC主催の講習会「[Codexを使いこなそう！アイディアを形にするUnity × AIゲーム制作ワークショップ](https://aic.keio.ac.jp/session_post/unity-ai-game-workshop/)」で制作しました。

[unityroomで公開中の「MILK RUN」をプレイする](https://unityroom.com/games/milkrun)

## 最初の配達

1. タイトルの「プレイする」から4コマの紙芝居を読み、「ミルクを届けにいく」を選びます。保育士を WASD で動かし、金色の矢印に沿って屋台に近づくと、哺乳瓶は自動で手に入ります。
2. 矢印が赤ちゃんの方向に切り替わります。マウスで見回し、矢印の先へ進みます。近づくだけでミルクを渡せます。
3. 最初の配達では機嫌ゲージが増え、そのまま右上の赤ちゃんの欄まで移動します。続いてハートで倒れる盾なしピーマンと、守るべき東西のおうちを映します。戦闘中に機嫌ゲージが減った子に、またミルクを届けましょう。
4. 操作が戻ったら、盾持ちピーマンに近づいて同じハートが盾で弾かれる様子を見ます。手ぶらで F または左クリックして盾を割ります。もう一度攻撃して本体を倒せば練習完了です。
5. 哺乳瓶を持っているときは、E または右クリックで床に置いてから攻撃します。練習中は敵から攻撃されません。Tab で練習を飛ばして開戦することもできます。

本番の開始と同時に案内の矢印が消えます。右上の3人のごきげん・空腹ゲージを見て、誰に届けるかを自分で決めます。左上は守る拠点である東西のおうちの耐久です。ミルク屋台には哺乳瓶、おうちには盾の旗があります。

## 全体マップ

画面右側に全体マップが表示されます。太い道と矢印が敵の進路です。赤い点が敵、「盾」が盾持ち、水色の四角が自分です。哺乳瓶がミルク補給所で、赤ちゃんは笑顔・泣き顔・赤い角のある顔で状態が分かります。M キーを押すと拡大し、もう一度押すと戻ります。おうちが攻撃されると、対応するおうちとマップが赤くなります。

## クリア報酬と2面「お菓子の町」

王冠ピーマンを撃破すると報酬カードが3枚並びます。クリックか 1・2・3 キーでカードの説明を開き、「この報酬で2面へ」か Enter で決定します。

| 報酬 | 2面での効果 |
| --- | --- |
| コウノトリ | 補給所からお腹が空いた赤ちゃんまで、ゆっくり飛んで自動でミルクを届ける |
| プロテインミルク | 補給所から受け取る3本に1本が特製ミルク。届けた子のハート攻撃が12秒間速くなる |
| ガラガラ | プレイヤーが左手に持ち、通常の打撃が3から4、ミルクを盗んだ相手へのクリティカルが8から9になる |

2面ではふたつのおうちを1分15秒守ると、東の入口からクッキー将軍が登場します。将軍にはハートと打撃が効きます。赤い輪が出たら大ジャンプに備えましょう。全体マップの「盗」がミルクどろぼうです。補給所までは速く、盗んだあとはゆっくり逃げます。赤ちゃんのハートは1ダメージで、どろぼうを倒せるのはプレイヤーです。基本の攻撃は3ダメージで、ミルクを盗んだ相手には8ダメージ。盗んだ相手を倒すと補給所が使えるようになります。敗北した場合、選んだ報酬で2面から再挑戦できます。

## 戦闘中の操作

| やりたいこと | 操作 |
| --- | --- |
| 移動・ジャンプ | WASD・Space |
| 見回す | マウスまたは矢印キー |
| カメラを近づける・遠ざける | マウスホイールを上・下に回す |
| ミルクを受け取り、届ける | 屋台・空腹の子に近づく。どちらも自動 |
| 哺乳瓶をいったん床に置く | 運んでいるときに E または右クリック。置くまで0.5秒 |
| 落とした哺乳瓶を拾い直す | 床の哺乳瓶のそばで E または右クリック |
| 敵を押し返す | 哺乳瓶を持っていないときに F または左クリック |
| 寝返った子を味方に戻す | 哺乳瓶を持たずに頭上に E が出た子のそばに立ち、E または右クリックを5秒間長押し |
| 休憩・やり直し | Esc |

## 音楽と音量

タイトルとお世話の練習では木琴とピチカートの「おもちゃの庭」が流れます。開戦のカットで準備曲が止まり、合図のあとに144 BPMの太鼓とブラスで新しい戦闘曲が始まります。王冠ピーマンが現れると専用曲に切り替わります。

哺乳瓶の受け取り・拾い直し、床に置くとき、ミルクを飲ませるときにはそれぞれ効果音が鳴ります。赤ちゃんの機嫌ゲージが空になると、短い泣き声が鳴ります。敵は進軍中と最初の攻撃時に頭上にセリフを出し、声風の効果音を鳴らします。

Esc の「ひとやすみ」で BGM 音量を10％ずつ調節できます。0％にすると効果音だけで遊べます。BGM 音量は次回の起動にも引き継がれます。

## 5分の発表で見せる流れ

攻撃練習が終わると、5秒のカウントダウンが始まります。カウントが終わると西の入口に最初の敵が現れます。おうちの紹介後は Tab で早めに開戦できます。敵が見張り砦を壊すカットのあとで、2分の防衛タイマーが動き出します。道の両側から次々に敵が来ます。どちらかのおうちの耐久がゼロになると敗北です。

敗北画面の「満タンでバトルから再挑戦」を選ぶと、赤ちゃん全員の機嫌ゲージが満タン、東西のおうちの耐久が100の状態で、2分の防衛をすぐ始めます。「チュートリアルから」を選ぶと、最初の配達と攻撃練習をもう一度遊べます。

敵の頭上にはHPと攻撃の結果が出ます。初登場の敵は画面上部で姿・入口・特徴を紹介します。1面のおじいちゃんは、防衛タイマーが残り1:00になったときに初登場します。盾持ちピーマンの盾は、手ぶらで F または左クリックを当てると割れます。1面には押し返しに強いブロッコリー、2面には転がってすばやく迫るクッキー兵が出ます。

1面の時計が 0:00 になると西の入口にボスが現れます。おうちの耐久、赤ちゃんの空腹、手荷物はそのままです。ボスの盾は打撃3回で割れ、体力が半分になるともう1回だけ盾を構えます。地面に赤い輪が出たら輪の外へ走るか、着地に合わせてジャンプしましょう。王冠ピーマンのHPがゼロになれば報酬選択へ進みます。

赤ちゃんは機嫌ゲージが空になると泣き始め、さらに10秒で寝返ります。1プレイで最初に寝返る子は、戦闘を一時停止して赤く変身するところをアップで映します。手ぶらで E または右クリックを5秒長押しすると、自分の台座まで走って味方の迎撃に戻ります。

## Unityでの編集

Unity Hub にこのフォルダーを追加し、6000.3.27f1 で Assets/Scenes/ToyGarden.unity を開いて Play。メニューの「Milk Run」から Mac または Windows をビルドすると Builds フォルダーに実行版ができます。

| スクリプト（Assets/Scripts 内） | 内容 |
| --- | --- |
| MilkRun.cs | プレイヤー操作、運搬、お世話、ウェーブ、勝敗 |
| MilkRunMusic.cs | 場面ごとのBGM、曲の切り替え、効果音との音量調整 |
| MilkRunSounds.cs | 泣き声、哺乳瓶を置く音、敵のセリフの効果音 |
| MilkRunSiege.cs | 防衛時間、おうちの紹介カメラ、盾の判定、ボスと踏みつけ |
| MilkRunGuide.cs | 練習中の配達先、足元の矢印、練習の的、走る動作 |
| MilkRunFeedback.cs・BabyExpression.cs | 表情となでる動作、敵の攻撃、おうちの被弾・崩壊と勝利演出 |
| ToyGarden.cs・ToyArt.cs | 庭の配置、目印、キャラクターの造形 |
| MilkRunMap.cs | 道、敵、赤ちゃん、補給所、おうちを表示する全体マップ |
| MilkRunScenes.cs | 初回配達の機嫌ゲージ、盾の解説、開戦カット |
| MilkRunEncounters.cs | 敵の初登場カットイン、最初の寝返りのアップ |
| MilkRunOpening.cs | タイトルと4コマに使う立体イラスト |
| MilkRunTown.cs | 2面への移行、3つの報酬、ミルクどろぼうと補給の復旧 |
| MilkRunUI.cs | 日本語の操作案内、画面端の矢印、敵のHP、結果画面 |
